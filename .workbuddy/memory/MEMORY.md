## ⚠️ 必须遵守的工作纪律（项目自己定的，出了问题才加的）1. **改完必须跑测试**：`cd 原型/游戏 && node _smoke.js` + `node _init_test.js`
2. **改完必须截图**：`node --check` 和单元测试**抓不到**块作用域错误 / 坏闭合标签 / CSS 假阳性 —— 这类错只有截图能看见（已发生 4 次）
3. **改完必须重新打包**：`node 原型/_build_release.js`。`原型/发布/秘境录/` 是**快照**，不跑就是旧界面
4. **同一时间只让一个会话改代码**：`_game.js` 8000+ 行，逐行合并不现实；两个会话同改会**互相覆盖**（Round 40 实际发生过）
