这是什么
----------------------------------------
一个挂机修仙游戏的原型：带弟子进秘境刷怪、捡装备、涨修为，
弟子寿元耗尽或战死之后把装备传承给下一代，宗门一代代变强。

界面做成了手机竖窗的样子（400×648），但请用【电脑】打开：
拖装备拼格子要用鼠标，触摸屏拖不动。
（想试手机的话可以打开看，只是拼装玩法会不好操作。）


怎么打开（这条很重要）
----------------------------------------
1. 把整个 zip 解压出来，得到一个文件夹。
2. 双击文件夹里的「index.html」。

⚠️ 请【不要】把 html 单独拖出来发/放：图片在旁边的 assets/ 里、
   字体在旁边的 字体/ 里，分开了就会变成没图没字。
⚠️ 不需要联网、不需要安装任何东西。推荐 Chrome 或 Edge。
⚠️ 存档存在浏览器本地。我发新版本给你时，如果存档结构变了会自动重开一局
   （原型阶段就这么处理的），不用手动清理。

zip 里还有一份「秘境录_机制验证器.html」，是个更早的机制小实验，
直接双击就能开，有空再看。


界面：底部两个页签
----------------------------------------
【境】 —— 打与看
  · 「进入秘境」开刷；不想看就挂着，它自己会一直打、一直掉、一直涨修为。
  · 「快进 12 秒」懒得等的时候用。
  · 「提前交接传承」：弟子还活着就让他把装备交出去、换代。
  · 场景里是你的弟子和怪，五行秘境场地会跟着当前秘境换。
  · 修为条是唯一的进度轴：灵气满了自动突破；境界越高，怪越强。
  · 「背包」抽屉（境页里的按钮）：
      左键点一件装备 → 看"换上去之后属性怎么变"
      右键点一件装备 → 直接分解成素材
      把装备【拖】进左边的经络图部位格就能穿上
      上面可以设"自动分解低于 XX"、"只看有提升"
      下面还有功法和法宝
  · 「当前弟子」抽屉：这个弟子的详细数据。

【宗】 —— 管理与传承
  · 宗门地图（三档：素 / 金顶 / 仙门），点建筑看功能和升级。
  · 传承：优先度、宝库怎么处置、传承池（花荣誉点提取东西）。
  · 弟子名册 + 后勤岗位：谁出去历练、谁留在宗门干活。
  · 锻造部：用素材重铸 / 转移 / 定向装备，还有训话、门规、门装模板。
  · 擂台战报（异步 PVP）、历代弟子、史册馆（史册 / 生平）。

另外：你不在的时候游戏也在推进（离线结算），
回来后会弹一块「你不在的时候」，把这段时间发生的事讲给你听。


一整局的循环
----------------------------------------
弟子（寿元按现实时间走，挂着也在减少）
  → 进秘境刷怪、涨修为、捡装备
  → 两种结局：寿元耗尽「善终」（装备完整带回）
              战斗中身亡（装备遗落，要靠后辈搜寻）
  → 传承给下一代 → 宗门跨代积累素材 / 荣誉 / 名册 / 门装模板
修为一共 24 档，从炼气到羽化飞仙，按现在的配表要十几代弟子。


想请你重点感受的
----------------------------------------
1. 挂机感：挂着的时候你会不会想回来瞄一眼？
   回来弹的「你不在的时候」你会认真看吗？还是看两眼就点掉？你其实想知道什么？
2. 弟子换代：弟子死的时候你是"心疼"还是"无所谓"？
   会不会真的想去培养下一代、去把遗落的东西搜回来？
3. 宗页的自动化：门规 / 训话 / 门装模板这类"设一次、之后自动跑"的东西，
   你愿意去调吗？还是根本不想管？默认规则合理吗？
4. 界面：竖窗 + 两个页签够用吗？有没有找不到的功能、看不懂的数字？
5. 拖装备拼经络图：是"有意思"还是"麻烦"？
6. 节奏：一局多久合适？修为爬得太快还是太慢？


反馈怎么给我
----------------------------------------
不用写得很正式，玩完之后随便说几句就行，比如：
  · 玩了几分钟、卡在哪一步
  · 哪一刻觉得有意思 / 哪一刻想关掉
  · 有没有报错（页面顶部出现红框的话，把红框里的字截个图发我）
  · 顺手带上版本号：页面【右下角】有行小字（现在是 {{V}}）

数值还是一次性手调的，没做平衡，看到离谱的数字不用惊讶，直接说。
按钮和面板之后还会改，一切以你屏幕上看到的为准。
