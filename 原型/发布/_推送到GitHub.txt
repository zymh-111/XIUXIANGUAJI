第一步：在 GitHub 建一个空仓库
----------------------------------------
打开 https://github.com/new

  仓库名：     mi-yu-lu        （或者你喜欢的名字）
  可见性：     Public（公开）或 Private（私有）都行
  ⚠️ 不要勾 "Add a README file"
  ⚠️ 不要勾 ".gitignore"
  ⚠️ 不要勾 "Choose a license"

  因为本地已经有这些了，勾了会冲突。

建好后 GitHub 会给你一个地址，长这样：
  https://github.com/你的用户名/mi-yu-lu.git

把那个地址发给我，我帮你配 remote 并推送。
（或者你也可以自己在终端跑下面第二步）


第二步：配 remote 并推送（两行命令）
----------------------------------------
在 D:\游戏资料库 目录下打开命令行，跑：

  git remote add origin https://github.com/你的用户名/mi-yu-lu.git
  git push -u origin master

第一次推送会弹出浏览器让你登录 GitHub 授权，跟着点就行。


第三步（可选）：以后每次更新
----------------------------------------
  git add -A
  git commit -m "说明这次改了什么"
  git push


如果你想要「正式的 Releases 下载页」
----------------------------------------
GitHub 的 Releases 页面比直接给 zip 更正式，步骤：

  1. 先推完代码（上面两步）
  2. 打开你仓库的 Releases 页 → "Create a new release"
  3. Tag 填 v3，标题填「秘境录 v3 · 首次公开」
  4. 把 D:\游戏资料库\原型\发布\秘境录_v3_发给朋友.zip 拖到附件区
  5. 发不发布都行，附件链接可以直接发给朋友

（我也可以帮你做这步，但同样需要你先建好仓库）
