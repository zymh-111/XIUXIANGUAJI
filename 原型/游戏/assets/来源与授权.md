## 弟子立绘 · `弟子/弟子_1..7.png`

| 项 | 内容 |
|---|---|
| **来源** | **AI 生成**（ComfyUI / LiblibAI） |
| **授权** | 生成工具支持商用；本仓库公开分发已获作者同意 |
| **规格** | `弟子_N.png` 64×64 · `弟子_N@2x.png` 84×84，透明背景 |
| **归一化** | 各形象按【角色高度】统一到占画布 ~80%，所以不同来源的图视觉大小一致 |
| **用途** | 「宗」页弟子名册头像 + 「境」页主角立绘 |

**形象与配色的分配规则**（`_game.js` 里 `AV_COUNT` / `AV_DISC`）：

- 形象编号 = `1 + (弟子id % 7)`
- 圆盘配色 = `AV_DISC[(弟子id - 1) % 7]`
- ⚠️ `AV_COUNT` **必须等于** `弟子/` 里的形象数，否则同批弟子的形象与颜色会重复

## 经络图 · `经络图_剪影.png` / `经络图_穴位.png`

| 项 | 内容 |
|---|---|
| **底本** | 《图注八十一难经》· **明代刻本** |
| **年代** | 明代（内容更早，作者传为扁鹊/秦越人，注者为明人） |
| **图像内容** | 正面人体经络图，含八会穴标注（气会膻中、藏会章门、筋会阳陵泉、髓会绝骨、脉会太渊、骨会大杼、血会膈俞、脏会章门） |
| **来源页** | [书格 shuge.org](https://www.shuge.org/view/tu_zhu_ba_shi_yi_nan_jing/) —— 公共版权古籍资源站 |
| **提取方式** | 从整页扫描裁切 → 遮罩 → 去纸纹 → 阈值化 alpha → 三色上色（脚本见原工作区 `美术资源/_提取经络图.py`） |
| **用途** | 「装」页的人体背景（`#zhuang`），部位格用引线指向对应身体位置 |

### ⚠️ 授权状态：**需要你确认**

| 层面 | 状态 |
|---|---|
| **底本（明代刻本）** | ✅ **公有领域** —— 早已过版权保护期，任何人都可用 |
| **扫描件来源** | ⚠️ **需留意** —— 书格站方通常声明站内资源「仅供个人学习研究使用」 |

**法律上**：对公有领域作品的**忠实复制**（faithful reproduction）在多数法域
（如美国 *Bridgeman v. Corel* 判例）**不产生新的著作权**。
**但**站方的**使用条款**是另一回事。

**原工作区的说明文档给出的建议**（按稳妥程度排序）：

1. **换一个来源**重取同一张图 —— 《图注八十一难经》《针灸大成》《御纂医宗金鉴》里的经络图大同小异，
   国家图书馆、中华古籍资源库等机构的公有领域资源更适合作为商用来
2. 直接询问书格站方
3. **自己重绘** —— 以这张图为蓝本描一遍（描摹公有领域作品产生的新作品归你）

> 🚨 **在解决这一点之前，这个素材建议只用于原型和演示，不要直接放进正式发行版本。**
