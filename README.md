# 秘境录 · 挂机修仙原型

> 一个「上班摸鱼」的修仙挂机游戏原型。挂着刷宝，有空时看掉落、调 BD。
>
> **你是超脱老祖 —— 本门开派祖师。弟子会死，你不会。**

---

## 这是什么

一个**单文件、离线、纯 DOM** 的挂机修仙原型。核心循环：

```
弟子进秘境 → 割草刷宝 → 涨修为 → 出更强的怪 → 更好的装备
     ↓ 弟子寿终 / 战死
下一代弟子入门 ← 上一代传承（装备 / 门规 / 宗门积累）
```

修为 24 档，从**炼气**一路到**羽化飞仙**。一代到不了顶，要十几代接力。

### 三个特殊之处

| 机制 | 说明 |
|---|---|
| **六乘区** | 伤害不是一个乘法算出来的，是六个乘区相乘 ⇒ 「纸面属性更高」未必更强 |
| **制度会记忆** | 训话每代重置；**立为门规**后跨代保留，并署名给立规的那代弟子 |
| **制度会僵化** | 弟子反复死在同一个秘境 ⇒ **自动成形一条积弊**，要花荣誉点才能破除 |

## 怎么玩

**方式一：直接下 zip**（推荐）

到 [Releases](../../releases) 下载 `秘境录_v3_发给朋友.zip`，解压后双击 `index.html`。
不需要联网、不需要安装任何东西。

**方式二：从仓库跑源码**

把 `原型/游戏/` 整个目录拷出来，双击 `index.html` 即可。
（`index.html` 通过 `<script src="_game.js">` 加载逻辑，两个文件必须在同一目录。）

| 层 | 内容 | 代表文档 |

## 跑测试

需要 Node.js（仓库用 bundled runtime 测过 Node 24）。

```bash
cd 原型/游戏
node _smoke.js        # 909 项断言
node _init_test.js    # 初始化自检（exit 0 = 通过）
```

> ⚠️ **改完测试套件本身之后要压测 20~30 次** —— DOM 桩漏实现某个方法时，
> 只在**真的走到那条分支的那一局**才会崩，而崩在测试中段会让**后面所有断言静默不跑**
> （R71 实际踩到：桩缺 `cloneNode`，触发闪避就崩，终端里只有一段堆栈，"通过 865 项"看着正常）。

`_smoke.js` 自带一个**最小 DOM 桩**（`global.document` / `localStorage` / `setTimeout`），
所以能在 Node 里跑完整的 `render()` 路径，不需要 jsdom。
